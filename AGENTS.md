# Repository guide

This repository builds an Angular Schematics package. The schematics in `src/` generate projects; the contents of `src/**/files/` are copied into those projects.

## Where to make changes

- `src/ng-new/` composes Angular's official workspace and application schematics with this template's features.
- `src/base/`, `src/auth/`, `src/ui/`, `src/i18n/`, `src/docker/`, and `src/ci/` contain feature schematics and generated files.
- `src/utils/versions.ts` is the single source for optional dependencies added to generated apps. Keep Angular framework packages aligned with the CLI version in `package.json`.
- `src/migrations.json` and `src/**/schema.json` define upgrade migrations and public schematic options.
- `dist/` is generated by `npm run build`; edit `src/`, not `dist/`.

## Working conventions

- Preserve Angular's official schematic helpers and AST-based edits where available.
- Keep generated apps standalone, strict, zoneless and OnPush by default.
- When changing a feature, keep its schema, schematic, generated files, README documentation and migration behavior in sync.
- Use the `angular-template-schematics` skill in `.agents/skills/angular-template-schematics/SKILL.md` for generator or dependency work.

## Useful commands

- `npm run build` compiles the package and copies schematic assets.
- `npm run lint` checks TypeScript sources and schematic tests.
- `npm run format:check` checks formatting.
- `npm test` builds first, then runs the schematic tests.
- `npm pack` prepares the installable package archive.
