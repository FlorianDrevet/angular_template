# Maintain this Angular template

1. Read the repository `AGENTS.md` and inspect the relevant schematic, schema, generated files, and tests before editing.
2. Keep generated dependency versions centralized in `src/utils/versions.ts`. Keep the root Angular CLI, DevKit and `@schematics/angular` versions aligned. Confirm Angular, Node and TypeScript compatibility from official Angular references and package peer dependencies.
3. For a new feature, add or update its schema, schematic registration in `src/collection.json`, implementation, and files under that feature's `files/` directory. Wire it into `src/ng-new/` when it belongs in the initial project generator.
4. Use Angular's AST helpers for TypeScript edits. Avoid regex edits to application source where an official schematic utility exists.
5. If generated output changes, update the README and the schematic tests. Preserve compatibility for existing projects by adding or updating a migration when required.
6. Run the relevant lint, formatting, schematic tests and package build before finishing. Use the `npm pack` plus generated-app workflow when a change affects package output or composition.

Generated `.ts`, `.html`, and config files under `src/**/files/` are output assets, not files compiled as this package's TypeScript source. Keep them valid for the Angular version targeted by the generator.
